# macserver 실행 방법 (버튼으로 실행)

## 가장 쉬운 방법 — 더블클릭

맥미니에서 `macserver` 폴더를 Finder로 연 뒤 **`macserver`** 앱 아이콘을 **더블클릭**하세요.

- **처음 더블클릭**하면 Terminal 창이 열리며 필요한 구성요소를 자동으로 설치합니다(1~3분). 끝나면 macserver 창이 뜹니다.
- **그다음부터는** 더블클릭만 하면 백그라운드에서 조용히 켜지고 창이 나타납니다.
- 이미 켜져 있으면 기존 창을 앞으로 가져옵니다.

> 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면, 앱을 **오른쪽 클릭 → 열기**를 한 번만 해주면 이후에는 더블클릭으로 열립니다.

### Dock에 올려두기 / 항상 켜두기

- 앱이 실행되면 메뉴 막대(화면 오른쪽 위)에 macserver 아이콘이 생깁니다. 이 아이콘 메뉴에서:
  - **콘솔 열기** — 설정/파일/화면 창 열기
  - **로그인 시 자동 실행** — 체크하면 맥미니를 켤 때마다 자동으로 켜져 **서버처럼 항상 동작**합니다.
  - **접속 주소** — 다른 기기에서 접속할 주소 복사
- `macserver` 앱 아이콘을 Dock으로 끌어다 놓으면 Dock에서도 한 번에 실행할 수 있어요.

## 처음 할 일 (딱 한 번)

1. 더블클릭 → 설치가 끝나면 **설정 마법사**가 열립니다.
2. 관리자 아이디/비밀번호를 만들고, 공유할 폴더 1개를 고릅니다.
3. **시스템 설정 > 개인정보 보호 및 보안**에서 두 가지를 허용합니다 (앱의 *설정 > macOS 권한* 화면에서 버튼으로 바로 열 수 있어요):
   - **화면 및 시스템 오디오 기록** → 화면을 보여주기 위해 필요 (허용 후 앱 재실행)
   - **손쉬운 사용** → 원격으로 마우스/키보드를 조작하기 위해 필요
   - 원격 '제어'까지 쓰려면 Xcode Command Line Tools가 필요합니다. 설치가 안 돼 있으면 Terminal에 `xcode-select --install` 를 한 번 실행한 뒤, 앱의 *설정 > macOS 권한* 에서 **다시 빌드**를 누르세요.

## 접속하기

앱 *설정 > 접속 주소* 에 나오는 주소를 다른 Mac/폰 브라우저에서 열고, 만든 계정으로 로그인하세요. 같은 Wi‑Fi면 `http://<맥미니 IP>:7777`.

## 버튼이 안 될 때 (대체 방법)

- Finder에서 **`run-macserver.command`** 더블클릭 — Terminal에서 실행.
- 또는 Terminal에서:
  ```bash
  cd macserver
  bash scripts/setup.sh
  npm start
  ```
- **Node.js가 없다는 안내**가 뜨면 [nodejs.org](https://nodejs.org/ko/download)에서 LTS 버전을 설치한 뒤 다시 더블클릭하세요.

## 독립 실행 앱(.app)으로 만들기 (선택)

Terminal 없이 완전히 독립적인 앱을 원하면, 한 번만 빌드하세요:
```bash
cd macserver && npm run dist
```
`dist/` 폴더에 `macserver.dmg` 와 `macserver.app` 이 생깁니다. `macserver.app` 을 응용 프로그램 폴더로 옮겨 쓰면 됩니다.

## 화면 제어 조작법 (모바일·PC 공통)

- **접속하면 자동으로 전체화면(몰입) 모드**로 시작해 화면을 최대한 크게 봅니다.
- 화면 **위쪽 가운데 손잡이**를 탭하면 **툴바가 내려와요.** 여기서 키보드·단축키·텍스트·확대·화질·클립보드·연결 끊기를 쓸 수 있어요.
- 툴바의 **"키보드"** 를 누르면 (폰에서는) 자판이 떠서 바로 타이핑돼요. 한글도 됩니다.
- 툴바의 **"창 모드(작게)"** 를 누르면 화면이 작아지고 옆에 패널이 생겨요. 다시 **"전체화면 모드"** 로 돌아갈 수 있어요.

### 터치 제스처 (폰/태블릿)
- 한 손가락 **탭 = 클릭**, 두 번 탭 = 더블클릭
- 한 손가락 **끌기 = 커서 이동**, **길게 눌러 끌기 = 드래그**(창 이동·선택)
- **두 손가락 탭 = 우클릭**, 두 손가락 **밀기 = 스크롤**
- **핀치 = 확대/축소**, 확대 상태에서 한 손가락으로 밀면 화면 이동
- 작은 버튼은 핀치로 확대해서 정확히 누르세요. 가로로 돌리면 더 크게 보여요.
